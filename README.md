# 🌸 PinkPulse — Aesthetic Pink Calculator 💕

A modern, visually stunning, feature-packed **Pink-Themed Calculator** web application built with HTML, CSS, and Vanilla JavaScript. Designed with glassmorphism, floating ambient background animations, multiple pink sub-themes, scientific functions, unit/tip converter, history log, Web Audio sound effects, and full keyboard navigation.

## ✨ Features

- 🎨 **Glassmorphism UI**: High-blur background cards, glossy borders, soft drop shadows, and dynamic `@keyframes floatOrbs` background ambient animations.
- 💖 **4 Pink Color Themes**:
  - 🌸 **Blush Soft**: Elegant pastel pink & cream.
  - 💖 **Neon Cyberpink**: Vibrant electric pink with dark futuristic glows.
  - 👑 **Rose Gold**: Warm metallic rose gold.
  - 🍇 **Dark Cherry**: Deep velvet burgundy pink.
- 🧮 **Standard & Scientific Modes**:
  - Trigonometric functions (`sin`, `cos`, `tan` with `DEG`/`RAD` toggle)
  - Logarithms (`log`, `ln`), exponentiation ($x^y$, $e^x$, $10^x$)
  - Factorial ($n!$), constants ($\pi$, $e$), percentages (`%`), square roots ($\sqrt{x}$)
- 📜 **Calculation History Drawer**: Saves past expressions and results with timestamps. Click any historical calculation to reload it into the display screen.
- 💡 **Built-in Tip & Unit Converter**: Split bill calculator & conversion for Length and Temperature.
- 🔊 **Web Audio Sound Effects**: Cute synthesized click sounds (no external audio files required!).
- ⌨️ **Full Keyboard Support**: Numpad, arithmetic operators, Enter, Backspace, Escape with visual keypress highlight animations.
- 📋 **Copy to Clipboard**: Quick copy result button with floating toast alert.

## 🚀 Quick Start

No installation or node modules required!

1. Clone this repository:
   ```bash
   git clone https://github.com/aditichaudhary05/pink-calculator.git
   cd pink-calculator
   ```
2. Open `index.html` in your web browser:
   ```bash
   # On macOS
   open index.html

   # On Windows
   start index.html

   # On Linux
   xdg-open index.html
   ```

## 🛠️ Built With

- **HTML5**: Semantic layout and tab structure.
- **CSS3**: Vanilla CSS with custom properties (CSS variables), keyframe animations, and backdrop blur glassmorphism.
- **JavaScript (ES6+)**: Vanilla JS math engine, Web Audio API sound synthesis, and local storage persistence.
